# Football League Manager

Self-contained web app showing youth football league tables, results and fixtures
across six age groups (U13–U18) for the 2025/26 and 2026/27 seasons.

`index.html` is the entire app — open it directly, or host it as a static site
(GitHub Pages, Vercel, Netlify). No build step, no backend; data is embedded and
persists per-browser in localStorage.
