Rosters are per season. Use the “move” dropdown beside a team to promote/relegate it to another division for this season.

⚙️ Generate Fixtures

Create a round-robin schedule for the current age group / season. Only needed if you're not importing fixtures from elsewhere. Replaces existing fixtures for the chosen division.

Breaks applied automatically: no fixtures from 22 Dec, resuming more than 7 days after 1 Jan; no fixtures on Easter weekend (Good Friday–Easter Monday). Team unavailable weekends (below) push just that team's match to the next free slot.
🚫 Team Unavailable Weekends

Each team may pick up to 4 weekends it cannot play (for the division selected above). Set these before generating fixtures — affected matches move to the next available slot.

✅ Data Check

Checks every result to confirm both teams belong to the recorded division for that season. Flags any team not on the division roster.

💾 Data Management
CSV imports add to the currently selected season (). New age groups / divisions are created automatically.
Teams CSV columns: Age Group, Division, Team
Results CSV columns: Age Group, Division, Round, Date, Home Team, Home Goals, Away Goals, Away Team, Source, Comments (Round/Date/Source/Comments optional; Source = Comet/Website/Manual; an optional Season column overrides the selected season). Importing the same match from a second source merges it and flags any score discrepancy.
